# FilTarpro by filmtarget (Android)

Build with Android Gradle Plugin 8.2.2 and Java 17, or push to GitHub and run the **Build APK** workflow to download the **FilTarpro-apk** artifact.

## Camera features

- Manual ISO, shutter, focus, white balance, exposure compensation, Flat / Log looks, and still / video capture through Camera2.
- FRONT / REAR switching and a LENS control that cycles the available camera IDs and physical lenses exposed by logical multi-camera devices.
- Rack focus, face and touch focus, a focus-peaking preview overlay, and a two-axis level meter.
- A direct aspect-ratio grid with selectable frame masks and adjustable black-bar opacity. Camera controls stay above the masked preview.
- Settings use a modal panel with a fixed Back / Return button; main-screen touches and gamepad actions are blocked while the panel is open.
- Bluetooth gamepad support, a live histogram, gallery, and multi-frame night capture.

New photos and videos are saved under FilTarpro media folders. The in-app gallery continues to include existing FlatCam media.
